Stardew Sim

Stardew Valley'nin tüm haritaları (259 harita: kasaba, çiftlik, tüm bina içleri, madenler, ada, festival varyantları) çıkarılıp simüle edilebilir hale getirildi. Amaç: yapay zekaların mod yaparken (yeni yer, bina, NPC, sprite) ekran görüntüsüne ihtiyaç duymadan tutarlı çalışması.

Web (bu sayfa)

  • Harita: haritayı seç, karaktere dokun/tıkla → oraya yürür (A*). Kapılara/warp'lara yürüyünce içeri girer. Klavye: ok tuşları/WASD, E/boşluk = önündeki karoyu incele. Mobil: D-pad, iki parmakla yakınlaştır, sürükle = kaydır.
  • ☰ menü: çarpışma katmanı (kırmızı=engel, mavi=su, sarı=kapı, siyah=boşluk), ızgara+koordinat, mevsim, Simülasyon (hedef harita + x,y → karakter kapılardan geçerek yürür), Mod testi (TMX yükle → yeni konum olarak gez ya da bir haritaya EditMap yaması olarak uygula; kontrol raporu alttaki panelde), giriş warpı ekleme, TMX/PNG indirme.
  • Bağlantı paylaşımı: #SeedShop@6,29/fall = harita@x,y/mevsim. AI'ın verdiği linki açınca tam o karo gelir.
  • Piksel: mobil uyumlu editör (kalem, silgi, kova, damlalık, çizgi, dikdörtgen, ayna, geri al), kare ızgarası, animasyon önizleme, PNG aç/indir, PXT metin (AI'ın yazdığı sprite metnini yapıştır → tuvale çiz; ya da tuvali metne çevirip AI'a ver), Haritada dene (çizdiğin NPC sayfasıyla haritada yürü).

Yapay zekalar için (CLI / MCP)

git clone https://github.com/Waifuhtr/Stardew-valley-mcp && cd Stardew-valley-mcp
node cli/sdv.mjs help          # harita/simülasyon
node cli/px.mjs help           # piksel
claude mcp add --scope user stardew-sim -- node "$PWD/mcp/server.mjs"   # MCP: sdv + px araçları

Token tasarrufu için önce metin: find → info → ascii x y w h → tile; görüntü sadece gerekirse (render --region). Ayrıntılı rehber: AGENTS.md.

sdv find saloon
sdv info SeedShop
sdv ascii Town 30 50 30 25          # . zemin # engel ~ su D kapı W kenar-warp ! aksiyon
sdv go Farm 64 15 Saloon 10 20      # çok haritalı yürüyüş simülasyonu
sdv fit Town 60 75 5 4 --door 62,78 # buraya 5x4 bina sığar mı?
sdv tmx JoshHouse -o MyHouse.tmx    # yeni yer için şablon
sdv check MyHouse.tmx               # tutarlılık kontrolü
sdv render Town --region 40,50,20,15 --actor 45,60,left --grid
px draw - -o item.png --scale 8     # PXT metninden PNG
px read sprites.png --frame 16,32,0 # PNG karesinden PXT

Her satır bir piksel satırı; 4k = kkkk. NPC sayfası: 64px genişlik, 16×32 kareler, satırlar aşağı/sağ/yukarı/sol.
